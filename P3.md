## **<u>CAPÍTULO 3: GENERALIDADES</u>** 

## **1.1 Objetivos** 

- Reutilizar el desarrollo web que realizo en la P2, y completarlo con Spring boot, Multicapas, teniendo Entity, DTO, Controller, Repository, Service y serviceImpl. 

- Debe tener conexión a la base de datos Mysql o Postgres.. 

## **1.2 Puntos que debe tener su sitio web** 

- Crear un CRUD (GET, POST, PUT, DELETE) 

- Deben ejecutar las APIS en Postman o con CURL 

- Deben tener al menos un select con JPA y el select Nativo 

- Debe tener al menos un DTO con Validaciones @SIZE, @EMAIL, @NOTNULL, @POSITIVE, @NOTBLANK 

- Debe tener al menos un CONTROLADOR con validaciones en el POST y el GET
