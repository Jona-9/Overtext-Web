## 1. Propósito de la Capa Repository

La **capa Repository** es la única que habla con la base de datos de Supabase (PostgreSQL). Cada repositorio es una interfaz que extiende `JpaRepository<Entidad, Long>`; Spring Data JPA genera su implementación en tiempo de ejecución, por lo que no se escribe código de acceso a datos manual (`EntityManager`, `ResultSet`, etc.).

Heredar de `JpaRepository` entrega sin escribir una línea los métodos `findAll`, `findById`, `save`, `deleteById` y `count`, que la capa Service (Capítulo 3.5) reutiliza para el CRUD.

## 3. Select con JPA (consulta derivada)

```java
List<Producto> findByActivoTrue();
```

Spring Data interpreta el nombre del método (`findBy` + `Activo` + `True`) y genera la consulta `WHERE activo = true`. No hay SQL escrito a mano: el nombre del método **es** la consulta.

- **Ventaja:** cero SQL, verificado al arrancar la aplicación; si el atributo `activo` no existiera en la entidad, el contexto de Spring no levantaría.
- **Límite:** las condiciones complejas (filtros combinados, ordenamientos específicos) vuelven ilegibles los nombres de método.

## 4. Select Nativo (`nativeQuery = true`)

```java
@Query(value = "SELECT * FROM producto WHERE stock > 0 AND activo = true ORDER BY precio ASC",
       nativeQuery = true)
List<Producto> listarProductosDisponiblesNativo();
```

Aquí el SQL se escribe tal como lo ejecuta PostgreSQL y opera sobre **tablas y columnas** (`producto`, `stock`), no sobre clases y atributos Java. Devuelve solo los productos activos con existencias, ordenados de menor a mayor precio, y es el que consume `GET /api/productos/nativos`.

## 5. JPA vs SQL Nativo

| Criterio | Consulta derivada JPA | Consulta nativa |
|---|---|---|
| Lenguaje | Nombre del método | SQL de PostgreSQL |
| Opera sobre | Atributos de la entidad | Tablas y columnas |
| Portabilidad entre motores | Alta | Baja (atada a PostgreSQL) |
| Validación | Al arrancar la aplicación | En la primera ejecución |
| Control del SQL / ordenamiento | Limitado | Total |
| Uso en OverText | Listado de activos, búsquedas por campo único | Catálogo disponible ordenado por precio |
